# ANIXIA ジャンル体系再設計・既存分類監査

更新日: 2026-11-26

## 目的

既存の `genres` をそのまま増築せず、作品内容を示すジャンルと、題材・舞台・作品形式・対象層・制作技法を分離する。既存データの削除や一括移行は、作品単位の根拠確認と対応表作成が終わるまで実施しない。

## 現状スナップショット

Supabase の `public.genres` と `public.anime_genres` を確認。

- ジャンルマスター: 323件
- `is_filterable = true`: 249件
- `is_filterable = false`: 74件
- 公開作品: 12,161件
- 公開作品のうち、表示対象ジャンルを1件以上持つ作品: 3,248件
- 非表示分類を1件以上持つ公開作品: 343件
- `anime.format` は既に `tv / movie / ova / ona / special / other / web` の enum を持つ

※上記は2026-11-26の監査時点の値。作品数は今後変動する。

## 暫定的な新分類体系

| 分類 | 役割 | 例 |
|---|---|---|
| ジャンル | 物語の主な作風・ジャンル | アクション、コメディ、ドラマ、ファンタジー、SF、ミステリー、ホラー、恋愛、サスペンス、スポーツ、歴史、戦争、音楽、日常 |
| テーマ・題材 | 物語が扱う主題・モチーフ | 学園、異世界、タイムトラベル、ロボット、魔法、超能力、宇宙、吸血鬼、ゾンビ、アイドル、バンド、料理、医療、軍事、探偵 |
| 舞台・世界観 | 物語の場所・時代・世界の性質 | 現代、日本、海外、未来、近未来、過去、終末世界、宇宙、架空世界 |
| 作品形式 | 公開・制作上の形式 | TV、劇場版、OVA、ONA、SPECIAL、WEB等。既存 `anime.format` を正本とし、ジャンルに重複登録しない |
| 対象・レーティング | 想定対象層と公式年齢区分 | 子供向け、少年向け、少女向け、青年向け、女性向け、全年齢、年齢制限。対象層と年齢レーティングは別フィールド |
| 制作・表現技法 | 映像の制作方法・表現 | 2D、3DCG、ストップモーション、実写との融合、特撮 |

この6分類は設計案であり、正式確定前に各項目の定義・境界・重複ルールを定める。

## 既存323件の一次トリアージ

名前の語句を使った機械的な振り分けを実施した。これは監査の入口であり、最終判定ではない。特に `film` を含む名称には、作品形式ではなく「犯罪映画」「戦争映画」のようにジャンルや題材を表すものもあるため、文字列だけで別分類へ移してはならない。

| 機械的な候補群 | 件数 | 現在表示 | 現在非表示 | 日本語名なし |
|---|---:|---:|---:|---:|
| 形式・媒体語を含む候補 | 129 | 63 | 66 | 39 |
| 題材・物語語を含む候補 | 51 | 51 | 0 | 14 |
| 対象層語を含む候補 | 8 | 7 | 1 | 1 |
| 制作・表現語を含む候補 | 7 | 6 | 1 | 2 |
| その他のジャンル・個別題材候補 | 128 | 122 | 6 | 16 |
| **合計** | **323** | **249** | **74** | **72** |

上記は優先順位付け用の単純な名前ベース集計。候補群は意味上の分類を保証しない。

## 明確な再分類候補の例

### 作品形式・媒体に移す候補
- `television series`, `anime television program`, `animated web series`
- `OVA` や `movie` 相当の形式語を含む分類
- `video game`, `game show`, `television program`

これらは `anime.format` または別の形式フィールドと重複しないよう整理する。

### テーマ・題材に移す候補
- `school anime and manga` → 学園
- `time-travel anime and manga` → タイムトラベル
- `vampire anime and manga` → 吸血鬼
- `idol anime and manga` → アイドル
- `band anime and manga` → バンド
- `magical girl anime and manga` → 魔法少女
- `military anime and manga` → 軍事

### 舞台・世界観に移す候補
- `isekai` → 異世界
- `post-apocalyptic fiction` → 終末世界・ポストアポカリプス
- `dystopian fiction` → ディストピア
- `alternate history` → 歴史改変

### 対象・レーティングに移す候補
- `children's anime`, `girls' anime`, `teen film` 等
- ただし「少年向け」「少女向け」などの対象層と、性的表現等に基づく年齢レーティングを混同しない。

### 制作・表現技法に移す候補
- `3D computer graphics`, `computer animation`, `puppet film`, `brickfilm`, `tokusatsu`
- 「アニメーション」は作品の媒体・制作表現であり、物語ジャンルとして扱わない。

## 統合・名称整理の候補

- `Action` と `action fiction` は同一ジャンルの重複候補。
- `Adventure` と `adventure fiction` は同一ジャンルの重複候補。
- `Comedy` と `comedy drama anime and manga` は単純統合せず、後者が「コメディ＋ドラマ」なのか複合ジャンルなのかを作品単位で確認する。
- `Suspense / Thriller` と `suspense anime and manga` は定義を整理し、サスペンスとスリラーを同義扱いするか別扱いするか決める。
- `Supernatural` と `supernatural fiction` は重複候補。
- `War` と `war film` は後者の映画形式語を取り除き、戦争ジャンル／題材へ統合できるか確認する。
- `coming-of-age film` と `coming-of-age anime and manga` は「青春・成長」へ統合候補。
- `film` で終わる名前を一律に削除・非表示にしない。例: `crime film`, `war film`, `musical film` は物語のジャンル・題材を示す可能性がある。

## 重大な品質課題

1. 日本語名がないマスターが72件ある。名称を推測で埋めず、意味を確認してから正式名称を設定する。
2. Wikidata由来の分類には、アニメのジャンルとして粒度が細かすぎるもの、他媒体向けのもの、一覧・番組・作品形式を示すものが混在する。
3. 作品への関連付けは分類マスターの名前だけでは正誤を判定できない。各作品の公式紹介・信頼できるデータソース等で検証する必要がある。
4. 現在の公開作品数12,161に対し、表示対象ジャンルを持つ作品は3,248件。分類体系の整理と並行して未分類作品の補完が必要。
5. `is_filterable` は現在の暫定的な表示制御にすぎず、6種類の分類体系を表現できない。

## 次の実装順

1. 全323件について、個別の移行先・統合先・維持理由・要確認理由を持つ対応表を作る。
2. 新マスターと作品関連テーブルを設計し、外部IDを新しい分類体系へ再マッピングする。
3. 作品ごとの根拠を保ったままデータを移行し、件数・重複・孤立関連を検証する。
4. フロントエンドの検索UIを6分類に分離する。
5. 旧 `genres` を削除するのは移行検証とロールバック確認の後に限る。

## 変更の安全性

この監査では読み取りのみを実施した。既存のジャンルマスター、作品との関連付け、外部IDは変更・削除していない。
